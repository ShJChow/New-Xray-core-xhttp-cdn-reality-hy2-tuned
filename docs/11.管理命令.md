# XHTTP + CDN 搭建指南 (十一)：管理命令 `xh`

安装脚本会把管理命令写到 `/usr/local/bin/xh`。不带参数进入交互菜单，也可直接调子命令。

所有子命令都需要 root。节点参数从 `/etc/xhttp-cdn/node.env`（权限 0600）读取。

---

## 子命令

| 命令 | 说明 |
|---|---|
| `xh` | 交互菜单 |
| `xh status` | 服务运行状态、监听端口、当前流控参数（qdisc / 拥塞算法 / rmem_max / tcp_fastopen）、xray 进程 nofile、Xray 与 Nginx 版本 |
| `xh info` | 节点参数（域名 / UUID / 公钥 / Short ID / Path / VLESS Encryption / xpadding / ECH）+ 客户端节点链接 |
| `xh sub` | 三条订阅链接 + V2RayN 订阅二维码 |
| `xh resub` | 手工编辑过 `~/client-config.txt` 后，按它重新生成订阅文件（无需重跑安装脚本） |
| `xh diag` | UDP / HTTP3 节点连不上时的服务端侧自检：`443 quic` 监听、`nginx -t`、UDP 443 监听、防火墙规则，并给出客户端侧自测步骤 |
| `xh log [xray\|nginx] [行数]` | 跟踪日志。systemd 下 xray 走 `journalctl`，OpenRC 下走 `/var/log/xray/error.log` |
| `xh start` / `stop` / `restart` | 控制 xray 与 nginx（存在 Hysteria2 时一并重启） |
| `xh update [--auto]` | 更新 Xray-core |
| `xh tuning [show\|off]` | 查看 / 回滚流控调优，详见 [10.流控调优.md](./10.流控调优.md)。**重新开启需重跑安装脚本**（调优依赖安装时的逐项能力探测），`xh tuning on` 只会提示这一点 |
| `xh keepalive [on\|off\|show]` | 保活开关 |
| `xh autoupdate [on\|off\|show]` | 内核自动更新开关 |
| `xh guard` | 单次健康检查，异常服务自动拉起（cron 调用，一般不用手动执行） |
| `xh uninstall` | 卸载全部组件 |
| `xh version` | 版本信息 |

---

## 内核更新与回滚

`xh update` 的流程：

1. 比对本地版本与 GitHub 上的 `XTLS/Xray-core` 最新 tag，一致则直接返回。
2. **先备份**当前二进制到 `/usr/local/bin/xray.bak-<旧版本号>`。
3. 非 Alpine 走官方 `install-release.sh`；Alpine 直接下载 zip 覆盖安装。
4. 下载或安装失败 → 立即回滚并重启。
5. `xray -test -config` 自检失败 → 回滚并重启。
6. 重启后服务未 active → 回滚并重启。

`--auto` 跳过确认提示，供 cron 使用。

---

## 保活与自动更新

安装时默认写入两条 cron（均带 `# xray-xhttp` 标记，便于识别与清理）：

```cron
*/5 * * * * /usr/local/bin/xh guard >/dev/null 2>&1 # xray-xhttp guard
@reboot     /usr/local/bin/xh guard >/dev/null 2>&1 # xray-xhttp guard
0 4 * * 0   /usr/local/bin/xh update --auto >/dev/null 2>&1 # xray-xhttp autoupdate
```

`xh guard` 逐个检查 xray / nginx（以及存在时的 hysteria-server），发现未运行就重启，并通过 `logger -t xray-xhttp` 写系统日志。

部署时可用环境变量关闭：

```bash
FEATURE_KEEPALIVE=false FEATURE_AUTOUPDATE=false bash ~/install-xpadding.sh
```

查看本项目的 cron：

```bash
crontab -l | grep 'xray-xhttp'
```

## 卸载

```bash
xh uninstall     # 需输入 yes 二次确认
```

会停止并删除 Xray / Nginx / Hysteria2 的服务与文件、acme.sh 与证书、本项目的 cron 与调优配置、`/etc/xhttp-cdn`、客户端配置与订阅文件，最后删除 `xh` 自身。

**保留**你自己上传的回落页面目录 `~/dist/<域名>/`。

手动卸载指令见 [9.卸载.md](./9.卸载.md)。
