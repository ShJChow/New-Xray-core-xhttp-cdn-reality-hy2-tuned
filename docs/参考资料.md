## 2. xpadding 填充防探测机制

- **背景与原理**：
  早期分块传输协议在首包握手阶段存在固定特征长度，易被中间设备（DPI）进行主动指纹识别。`xpadding` 通过对数据帧插入伪随机填充，抹除报文长度特征。
- **权威讨论与代码演进**：
  - [Xray-core Issue #4346: Solution to the xpadding leak](https://github.com/XTLS/Xray-core/issues/4346)

  - [Xray-core v26.2.6 Release](https://github.com/XTLS/Xray-core/releases/tag/v26.2.6)

## 5. Linux 内核流控与网络调优

- **BBRv3 拥塞控制**：
  - Linux Kernel TCP BBRv3 核心补丁集与带宽延迟积 (BDP) 计算模型。
  - 单流 TCP/Socket 缓冲区（`net.core.rmem_max` / `net.ipv4.tcp_rmem`）64MB 全局保护上限设计，保障大带宽低丢包与多并发下的内存安全边界。
- **Nginx 反向代理与 HTTP/3 广播**：
  - RFC 9114: HTTP/3 (HTTP over QUIC)。
  - RFC 7838: HTTP Alternative Services (`Alt-Svc` 广播声明：`h3=":443"; ma=86400`)。
  - Nginx `epoll` 多核亲和度、`reuseport` 与 65535 大并发连接池配置最佳实践。
